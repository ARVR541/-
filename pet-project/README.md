# Калькулятор определителя матрицы

Веб-приложение вычисляет определитель квадратной матрицы размером от 2×2 до 8×8. Для матриц 3×3 можно выбрать правило Саррюса. Для остальных размеров используется разложение Лапласа по строке или столбцу. В результате отображается точное значение, десятичное приближение и, по желанию, ход вычислений.

Рабочая версия: [Калькулятор определителя](https://arvr541.github.io/-/pet-project/).

## Запуск

Из папки с `index.html` запустите `python3 -m http.server 8000` и откройте `http://localhost:8000`. Локальный сервер нужен для загрузки JavaScript-модулей. Для оформления формул MathJax загружается из CDN.

## Как проверить

1. Откройте приложение, оставьте размер 3 и нажмите «Примеры».
2. Выберите метод Саррюса и нажмите «Посчитать». Определитель равен 1.
3. Выберите разложение Лапласа и вычислите тот же пример. Ответ также равен 1.
4. Измените размер на 2. Приложение перестроит поля и переключится на метод Лапласа.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html`, `redesign.css` | Разметка и оформление |
| `main.js` | Связывает кнопки, вычисления и вывод |
| `matrix-input.js` | Создаёт поля матрицы, читает и проверяет ввод |
| `rational.js` | Хранит числа как дроби и выполняет точные операции |
| `determinant.js` | Реализует правило Саррюса и разложение Лапласа |
| `solution-renderer.js` | Выводит формулы, шаги и результат |

Поля матрицы и результаты обновляются средствами нативного DOM. MathJax отвечает за отображение формул. При подготовке к практике исходная логика существующего проекта вынесена из HTML в модули, также исправлены ошибки разбора чисел и переключения метода.
